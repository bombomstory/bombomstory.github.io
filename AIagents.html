🔴 ลำดับที่ 1: งานด่วนที่สุด (สั่ง AI วันนี้ เพื่อใช้งานทันที)

1.1 ระบบแก้จน ppaos.com

Coding Assistant

เป้าหมาย: ช่วยเขียนคำสั่ง SQL สำหรับ Clean Data และโค้ด Backend

ฉันทำระบบเว็บด้วย [ระบุภาษา เช่น PHP + MySQL] โครงสร้างตารางชื่อ `users` มีคอลัมน์ `province`. ช่วยเขียน SQL Query สำหรับลบข้อมูลที่ซ้ำซ้อนของ 'อำนาจเจริญ' และเขียนฟังก์ชัน API สำหรับผูกกับปุ่ม 'เคลียร์ดาต้า' ให้หน่อย

1.2 สอนพิเศษ กส.พิทย์

Teaching Assistant

เป้าหมาย: ร่างหัวข้อสไลด์ และสร้างโจทย์แบบฝึกหัด/ควิซ

พรุ่งนี้ฉันต้องไปสอนพิเศษเด็ก ม.ปลาย หัวข้อ [ระบุวิชา/เนื้อหา] เป็นเวลา 2 วัน ช่วยร่างโครงสร้างสไลด์การสอนแบบแบ่งเนื้อหาตามวันให้หน่อย และขอโจทย์ทดสอบความเข้าใจ 5 ข้อ พร้อมเฉลย

🟠 ลำดับที่ 2: งานระยะสั้น (สั่ง AI จันทร์-อังคาร 20-21 ก.ค.)

2.1 เตรียมสอน Embedded

Content Gen.

ช่วยออกแบบใบงาน (Lab Sheet) สำหรับสอนวิชา Embedded System ระดับมหาวิทยาลัย หัวข้อ [การอ่านค่าเซ็นเซอร์] ใช้บอร์ด ESP32 ช่วยเขียนตัวอย่างโค้ด C++ พร้อมคอมเมนต์อธิบายแต่ละบรรทัดให้ด้วย

2.2 วิทยากร รร.ทุ่งกุลา

Copywriter

ช่วยร่างวาระการประชุมสั้นๆ เพื่อเตรียมคุยกับทีมงานเรื่องการจัดค่ายวิชาการ รร.ทุ่งกุลา และช่วยร่างโครงสร้างจดหมายเชิญวิทยากร (หนังสือครุฑ) เพื่อส่งให้โรงเรียนเป็นตัวอย่าง

2.3 วิทยากร จ.ร้อยเอ็ด

Communicator

ช่วยร่างข้อความทาง LINE แบบเป็นทางการแต่มีความเป็นกันเอง เพื่อเชิญอาจารย์ 3 ท่านมาเป็นวิทยากรที่ร้อยเอ็ด และขอนัดเวลาโทรคุยรายละเอียดในวันที่ 24 ก.ค. นี้

🟡 ลำดับที่ 3: งานโปรเจกต์/วิชาการ (ทยอยสั่ง AI พุธ-ศุกร์)

3.1 ข้อเสนอ AI (4 ล้าน)

Grant Writer

ฉันกำลังร่างโครงการขอทุน 4 ล้านบาท หัวข้อ 'การใช้ AI พัฒนาการศึกษา'. ช่วยเขียน 'หลักการและเหตุผล' ความยาว 3 ย่อหน้า ด้วยภาษาทางการราชการ และช่วยลิสต์หัวข้อเทคโนโลยี AI ที่ควรใส่

3.2 วิจัย TCI 1

Research Asst.

นี่คือบทคัดย่อ (Abstract) ที่ฉันเขียน [วางเนื้อหา] ช่วยปรับแก้แกรมม่าให้เป็นภาษาอังกฤษระดับ Academic และทำให้กระชับขึ้น. หรือ ช่วยสรุปเปเปอร์นี้เป็น Bullet Points [วาง text ของเปเปอร์]

3.3 QA (SAR/CAR)

QA Editor

มีคอมเมนต์จากการประเมิน QA ดังนี้: [วางคอมเมนต์] ช่วยเขียนสรุปแนวทางแก้ไขปรับปรุง (CAR) เป็นข้อๆ ด้วยภาษาที่เป็นทางการและดูเป็นรูปธรรมให้หน่อย

🟢 ลำดับที่ 4: งานอื่นๆ (สั่ง AI เมื่อมีเวลาว่าง)

4.1 จัดซื้อวัสดุ/TOR

Procurement

ช่วยร่างรายละเอียดคุณลักษณะเฉพาะ (TOR) สำหรับการจัดซื้อคอมพิวเตอร์ จำนวน 10 เครื่อง งบเครื่องละไม่เกิน 30,000 บาท สำหรับใช้ในห้องปฏิบัติการคอมพิวเตอร์ของสาขา

4.2 กติกาแข่ง e-Sport

Event Planner

ช่วยร่างกฎกติกาการแข่งขัน E-Sport เกม RoV แบบทัวร์นาเมนต์ออนไลน์ และร่างแคปชั่น Facebook สำหรับเปิดรับสมัครนักศึกษาเข้าร่วมแข่งขัน พร้อมระบุช่องทางติดต่อ
